## 五、字段填写规范

每条档案是一个 JSON 对象，字段如下：

| 字段 | 必填 | 要求 | 示例 |
|---|---|---|---|
| `id` | ✅ | 不要改，保持 `NH-001` 这种格式 | `NH-001` |
| `name` | ✅ | 官方名称 | 杨柳青木版年画 |
| `school` | ✅ | 流派简称 | 杨柳青 |
| `category` | ✅ | 非遗类别 | 传统美术 |
| `batch` | ✅ | **完整批次名** | 第一批国家级非物质文化遗产 |
| `region` | ✅ | 省 + 市 + 区县 | 天津市西青区杨柳青镇 |
| `inheritor` | ✅ | **代表性传承人姓名**，多位用顿号 | 霍庆有、王文达（示例，请核对） |
| `technique` | ✅ | 制作技法 | 半印半绘 |
| `style` | ✅ | 风格特征，一句话 | 色彩雅致、构图饱满 |
| `themes` | ✅ | 常见题材，3–5 个 | `["仕女","娃娃","戏曲故事"]` |
| `symbolism` | ✅ | 寓意与由来 | 莲与鱼谐音"连年有余" |
| `summary` | ✅ | **300–500 字**规范介绍 | …… |
| `process` | ✅ | 工艺流程，分步骤 | `["勾描画稿","雕版","套印"]` |
| `materials` | ✅ | 主要材料 | `["梨木版","宣纸"]` |
| `sources` | ✅ | **真实来源，至少 1 条** | `["中国非物质文化遗产网"]` |

## 六、去哪查资料

| 来源 | 地址 | 说明 |
|---|---|---|
| **中国非物质文化遗产网** | `ihchina.cn` | 最权威，有国家级名录和项目编号 |
| 各省非遗保护中心 | 搜"省名 + 非遗保护中心" | 地方性细节更全 |
| 中国国家图书馆 | `nlc.cn` | 查古籍和学术资料 |
| 各地年画博物馆 | 天津杨柳青、苏州桃花坞、潍坊杨家埠 | 官方介绍可信 |

**不要用**：百度百科、自媒体文章、小红书笔记 —— 错误率高，且无法溯源。

## 七、改完怎么验证

### 步骤 1：确认 JSON 格式没坏

改完后，在 VS Code 里看文件有没有红色波浪线。有的话说明 JSON 写错了（多半是少了逗号或引号）。

### 步骤 2：告诉 B，让他重建向量

```powershell
npm run embed
```

### 步骤 3：网页刷新，测试

打开 `http://localhost:3000`，问一句相关问题，看 AI 回答的内容是不是你新写的那版。
