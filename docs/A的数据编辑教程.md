# 怎么修改和补充年画数据（给 A 的教程）

> 目标：让你能在 `data/ich-items.json` 里改内容、加条目，并且保证不出错。

---

# 一、先选一种方式

| 方式 | 难度 | 适合谁 | 需要装软件 |
|---|---|---|---|
| **方式一：GitHub 网页直接改** | ⭐ 最简单 | 只想改几条文字 | ❌ 不用 |
| **方式二：本地 VS Code** | ⭐⭐ 推荐 | 要补 6–8 条、大量修改 | ✅ 需要 Git + VS Code |

**建议**：第一次先用方式一改 1 条试试，找到感觉后换方式二。

---

# 方式一：GitHub 网页直接改（零安装）

## 步骤 1 · 打开文件

浏览器访问：

```
https://github.com/liyuxuan200817-commits/After-the-Rain/blob/main/data/ich-items.json
```

> 如果打不开，先打开梯子。

## 步骤 2 · 点编辑

页面右上角有一个 **铅笔图标 ✏️**（Edit this file），点它。

## 步骤 3 · 修改内容

在文本框里直接改。比如把这一行：

```json
"inheritor": "（待 A 补充）",
```

改成：

```json
"inheritor": "霍庆有、王文达",
```

## 步骤 4 · 提交

页面**拉到最底部**，找到 **「Commit changes」** 区域：

- 上面的输入框写一句说明，比如：`data: 补充杨柳青传承人`
- 选 **「Commit directly to the main branch」**
- 点绿色的 **「Commit changes」**

✅ 改完了。

## ⚠️ 方式一的缺点

网页编辑器**不会提示 JSON 语法错误**。少一个逗号，整个文件就失效，程序直接报错。

所以每条改完，**先看页面上方有没有红色报错条**。

# 方式二：本地 VS Code（推荐）

## 步骤 1 · 把项目拉下来（只做一次）

打开 PowerShell 或 VS Code 终端：

```powershell
cd D:\dev\projects
git clone https://github.com/liyuxuan200817-commits/After-the-Rain.git after-the-rain
```

> 如果提示 "Repository not found"，检查梯子是否开着。

## 步骤 2 · 用 VS Code 打开

```powershell
code D:\dev\projects\after-the-rain
```

或者：VS Code → 文件 → 打开文件夹 → 选这个目录。

## 步骤 3 · 打开数据文件

左侧点 `data` → 点 `ich-items.json`。

**你会看到这样的结构：**

```json
[
  {
    "id": "NH-001",
    "name": "杨柳青木版年画",
    "inheritor": "（待 A 补充）",
    ...
  },
  {
    "id": "NH-002",
    ...
  }
]
```

## 步骤 4 · 改内容（重点看这几种情况）

### 情况 1：改已有的文字

找到要改的那一行，直接改引号里面的内容。

```json
改之前：  "inheritor": "（待 A 补充）",
改之后：  "inheritor": "霍庆有、王文达",
```

⚠️ **只改引号里面的字，引号和逗号都不要动。**

### 情况 2：改数组（有中括号的字段）

```json
改之前：  "themes": ["仕女", "娃娃"],
改之后：  "themes": ["仕女", "娃娃", "戏曲故事", "吉祥图案"],
```

规则：每个元素用 `" "` 包住，之间用 **英文逗号** 隔开，最后一个**不加逗号**。

### 情况 3：加一条新档案

找到整个文件**最后一条**记录的结尾：

```json
    "sources": ["中国非物质文化遗产网"]
  }        ← 这里是最后一条的结尾
]          ← 这是整个数组的结尾
```

在 `}` 后面**加一个英文逗号**，然后粘贴新的一条：

```json
    "sources": ["中国非物质文化遗产网"]
  },       ← 注意这里加了逗号
  {
    "id": "NH-009",
    "name": "门神·秦琼敬德",
    "school": "杨柳青",
    "category": "传统美术",
    "batch": "第一批国家级非物质文化遗产",
    "region": "天津市西青区杨柳青镇",
    "inheritor": "（填写传承人）",
    "technique": "木版套印后手工彩绘",
    "style": "人物威猛，色彩浓重",
    "themes": ["门神", "武门神"],
    "symbolism": "秦琼、尉迟恭守门驱邪，护佑家宅平安",
    "summary": "这里写 300-500 字的规范介绍……",
    "process": ["勾描画稿", "雕版", "套印", "彩绘开脸"],
    "materials": ["梨木版", "宣纸", "矿物颜料"],
    "sources": ["中国非物质文化遗产网 · 杨柳青木版年画"]
  }
]
```

⚠️ **最后一条的 `}` 后面不能有逗号**，否则报错。

## 步骤 5 · 检查有没有写错

**看左侧文件名旁边有没有红点，或者编辑器里有没有红色波浪线。**

有红色 = 语法错了。鼠标悬停上去，VS Code 会告诉你哪一行有问题。

## 步骤 6 · 让改动生效

在终端里运行：

```powershell
npm run embed
```

看到这个就成功了：

```
📚 读到 9 条年画档案
✅ 拿到 9 个向量
💾 已保存到 ...\data\vectors.json
```

## 步骤 7 · 提交（推回 GitHub）

```powershell
git add .
git commit -m "data: 补充杨柳青等 3 条档案"
git push
```

> 如果 push 失败，多半是梯子没开或端口变了。
> 让 B 帮你跑 `.\push.ps1 "说明"` 就行。

# 二、五个必踩的坑（重点看）

## 坑 1：中文引号 ❌

```json
错误：  "name": "杨柳青",     ← 这里的引号是中文的 “ ”
正确：  "name": "杨柳青",     ← 必须是英文的 " "
```

**判断方法**：中文引号是圆润的 `“ ”`，英文引号是直的 `" "`。

**预防**：在 VS Code 里，中文引号会显示成不同颜色或者直接报错。

## 坑 2：中文冒号 ❌

```json
错误：  "name"： "杨柳青"      ← 冒号是中文的 ：
正确：  "name": "杨柳青"       ← 必须是英文的 :
```

**预防**：用英文输入法打冒号。

## 坑 3：最后一项多加了逗号 ❌

```json
错误：
  "sources": ["非遗网"],
}                ← 最后一项后面多了逗号

正确：
  "sources": ["非遗网"]
}
```

## 坑 4：漏了逗号 ❌

```json
错误：
  "name": "杨柳青"
  "school": "杨柳青"        ← 上一行末尾少了逗号

正确：
  "name": "杨柳青",
  "school": "杨柳青"
```

## 坑 5：正文里出现英文引号 ❌

如果简介里要写引号，必须**转义**（前面加反斜杠 `\`）：

```json
错误：  "summary": "俗称"门神画"，多贴于大门"
正确：  "summary": "俗称\"门神画\"，多贴于大门"
```

**更简单的办法**：正文里改用中文引号「」或《》，就不用转义了：

```json
"summary": "俗称「门神画」，多贴于大门"
```

# 三、改错了怎么办

## 如果还没提交

按 `Ctrl + Z` 撤销就行。

## 如果已经提交到 GitHub

**方案 1：改回来重新提交**

再改一遍，再 commit 一次。

**方案 2：让 B 帮你回退**

告诉 B「数据文件改坏了，帮我还原到上一个版本」，他一条命令就能处理。

# 四、怎么确认自己改对了

按这个顺序检查，**三步都过才算完成**：

```
第 1 步：VS Code 里没红线
        ↓
第 2 步：npm run embed 显示「读到 N 条」且数量和预期一致
        ↓
第 3 步：网页 localhost:3000 刷新，能看到你新写的内容
```

# 五、写内容的规范（不是格式，是内容质量）

## ✅ 应该这样写

```json
"summary": "杨柳青木版年画兴起于明代，盛于清代，因产于天津杨柳青镇而得名。
它最独特之处在于半印半绘：先用木版套印出墨线轮廓，再由画工手工敷彩、开脸，
因此人物面部神态细腻，色彩过渡柔和。题材以仕女、胖娃娃、戏曲故事为主。"
```

特点：**有具体年代、有具体地名、有具体技法、不空泛。**

## ❌ 不要这样写

```json
"summary": "杨柳青年画非常有名，历史悠久，是中国传统文化的瑰宝，
具有很高的艺术价值和历史价值，深受人们喜爱。"
```

问题：**全是空话，没有任何具体信息。** 这种内容放进"馆藏"里毫无价值。

## 判断标准

> **你写的每一句话，都应该是"查证后的结论"，而不是"感觉上的评价"。**

# 六、一次改多少合适

| 阶段 | 建议 |
|---|---|
| 第一次 | **只改 1 条**，完整走一遍流程 |
| 第二次 | 改 3 条，确认没问题 |
| 之后 | 一次改 5 条以内，改完就提交 |

**不要一次性改 8 条再提交** —— 如果格式错了，你很难定位是哪一条出的问题。

| 情况 | 找谁 |
|---|---|
